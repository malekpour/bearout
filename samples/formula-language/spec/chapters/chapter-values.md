# Literals and references

## Purpose

The primary expressions: numeric literals, string literals in double quotes
with `""` as the escaped quote, the boolean keywords, cell references such as
`A1` or `$B$2`, and ranges such as `A1:B3`. A bare identifier that is not a
function call is not an expression.
