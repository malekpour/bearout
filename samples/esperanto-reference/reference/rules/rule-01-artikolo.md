# Regulo 1: La artikolo / The article

## Regulo

Ekzistas nur unu difina artikolo, *la*, sama por ĉiuj seksoj, nombroj kaj
kazoj. Nedifina artikolo ne ekzistas.

## Rule

There is only one definite article, *la*, the same for all genders,
numbers, and cases. There is no indefinite article.
