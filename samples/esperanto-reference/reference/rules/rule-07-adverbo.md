# Regulo 7: La adverbo / The adverb

## Regulo

Adverboj finiĝas per *-e*; la gradoj de komparado estas kiel ĉe adjektivoj.

## Rule

Adverbs end in *-e*; the degrees of comparison are as for adjectives.
