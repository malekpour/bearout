# Regulo 3: La adjektivo / The adjective

## Regulo

Adjektivoj finiĝas per *-a* kaj akordiĝas kun la substantivo en kazo kaj
nombro. La komparativo uzas *pli*, la superlativo *plej*.

## Rule

Adjectives end in *-a* and agree with the noun in case and number. The
comparative uses *pli*, the superlative *plej*.
