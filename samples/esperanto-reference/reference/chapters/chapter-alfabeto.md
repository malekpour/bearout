# Alfabeto kaj prononco / Alphabet and pronunciation

## Celo

La alfabeto havas 28 literojn; ĉiu vorto legiĝas kiel ĝi estas skribita, kaj
la akcento estas sur la antaŭlasta silabo. Vidu
[regulon 9](../rules/rule-09-prononco.md#regulo) kaj
[regulon 10](../rules/rule-10-akcento.md#regulo).

## Purpose

The alphabet has 28 letters; every word is read as written, and the accent
falls on the penultimate syllable. See
[rule 9](../rules/rule-09-prononco.md#rule) and
[rule 10](../rules/rule-10-akcento.md#rule).
